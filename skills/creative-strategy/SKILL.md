# Estratégia de Criativos

Na Meta atual, o criativo é a principal segmentação: ângulos diferentes encontram públicos diferentes.

## 1. Ângulos (o "porquê" do anúncio)
Dor · Desejo/resultado · Prova social · Autoridade · Objeção quebrada · Comparação (vs. alternativa) · Novidade/mecanismo · Urgência real · Identidade ("para quem…") · Bastidores/processo.

## 2. Hooks (primeiros 1–3 s / primeira linha)
- Pergunta de dor: "Seu [X] também faz isso?"
- Afirmação contraintuitiva: "Pare de [ação comum] se quer [resultado]"
- Resultado: "Como [pessoa] conseguiu [resultado] em [prazo]"
- Demonstração visual imediata do produto funcionando
- "POV:" / tendência nativa da plataforma
- Lista: "3 erros que…"
Visual + texto na tela + fala devem dizer a mesma coisa.

## 3. Formatos
| Formato | Bom para |
|---|---|
| UGC/depoimento vertical 9:16 | Confiança, e-commerce, serviços |
| Demonstração / antes-depois (dentro das políticas) | Produto físico |
| Estático com headline forte | Teste rápido de ângulo |
| Carrossel | Vários produtos, passo a passo, objeções |
| Talking head / especialista | Infoproduto, serviços |
| VSL curta (30–90 s) | Oferta que precisa de explicação |

## 4. Roteiro curto (vídeo 15–45 s)
Hook (0–3 s) → Problema (3–8 s) → Solução/demonstração (8–25 s) → Prova (25–35 s) → Oferta + CTA (final). Legendas sempre.

## 5. Matriz de teste
Teste **1 variável por vez**: primeiro ângulo (3–5 conceitos diferentes), depois hooks do ângulo vencedor (3–5), depois formato/CTA.
Tabela: ID | Ângulo | Hook | Formato | Hipótese | Métrica de decisão (hook rate/CTR/CPA).

## 6. Briefing para produção
Objetivo · público · ângulo · hook exato · roteiro/cenas · texto na tela · formato e proporções (9:16, 4:5, 1:1) · duração · referências · CTA · o que evitar.

## Entregável padrão
3–5 conceitos (ângulo + hook + formato + descrição visual/roteiro) + matriz de teste + briefing.
