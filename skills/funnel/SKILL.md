# Funil

## Escolha do funil pelo ticket e consciência
| Ticket / contexto | Funil recomendado |
|---|---|
| Baixo (até ~R$100), impulso | Anúncio → página de vendas/produto → checkout (+ order bump) |
| Médio (R$100–1.000) | Anúncio → conteúdo/VSL ou isca → página de vendas → remarketing |
| Alto / serviço | Anúncio → captura/quiz ou WhatsApp → qualificação → call/proposta |
| Local | Anúncio → WhatsApp/ligação/rota |
| Lançamento | Captação de leads → aquecimento → carrinho aberto → remarketing |

## Etapas e campanhas
- **Topo**: alcance/vídeo/tráfego qualificado; métrica: custo por engajamento qualificado, hook rate.
- **Meio**: leads/visitas de página de vendas; métrica: CPL, taxa de conversão da página.
- **Fundo**: remarketing + conversão; métrica: CPA, ROAS.
Com orçamento pequeno, uma campanha de conversão já cobre o funil; não crie etapas sem volume.

## Aumentar valor por cliente
Order bump (complemento barato no checkout), upsell pós-compra, recorrência/assinatura, recompra por e-mail/WhatsApp. LTV maior permite CPA maior.

## Entregável padrão
Diagrama em texto (etapa → peça → campanha → métrica → meta) + ofertas por etapa + automações de follow-up (e-mail/WhatsApp) sugeridas.
